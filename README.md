# 🤖 Resolução de Desafios em Python com GitHub Copilot

Este repositório foi desenvolvido como parte de um desafio de projeto na **DIO (Digital Innovation One)**. O objetivo principal é consolidar fundamentos da linguagem Python e explorar o uso do **GitHub Copilot** como assistente de inteligência artificial para acelerar o desenvolvimento e a resolução de algoritmos simples.

## 🎯 Desafios Resolvidos

O projeto consiste em três scripts estruturados de forma direta e limpa (sem comentários internos), focados em resolver problemas quotidianos de lógica:

1. **`concat_dados.py`**: Recebe duas entradas distintas do utilizador e realiza a concatenação delas numa única string de saída.
2. **`ope_mat.py`**: Solicita dois números como entrada e realiza uma operação matemática simples (soma) entre eles.
3. **`repet_txt.py`**: Solicita uma string e um número inteiro para realizar a repetição do texto conforme a quantidade informada.

## 💻 Códigos-Fonte

### `concat_dados.py`
```python
dado1 = input()
dado2 = input()

resultado = dado1 + " " + dado2

print(resultado)
```

### `ope_mat.py`
```python
num1 = float(input())
num2 = float(input())

resultado = num1 + num2

print(resultado)
```

### `repet_txt.py`
```python
texto = input()
numero_repeticoes = int(input())

resultado = (texto + " ") * numero_repeticoes

print(resultado)
```

## 🚀 Tecnologias Utilizadas

* **Python 3.x**: Linguagem de programação para codificação das soluções.
* **GitHub Copilot**: Ferramenta de IA utilizada para ganho de produtividade no processo de desenvolvimento.
* **Git & GitHub**: Ferramentas para controlo de versão e alojamento do código.

## 🛠️ Como Executar o Projeto

1. Certifique-se de que tem o Python instalado na sua máquina.
2. Clone este repositório:
   ```bash
   git clone [https://github.com/WellingtonViniciuz/resolvendo-codigos-python-copilot.git](https://github.com/WellingtonViniciuz/resolvendo-codigos-python-copilot.git)
   ```
3. Aceda ao diretório do projeto e execute qualquer um dos scripts utilizando o terminal:
   ```bash
   python concat_dados.py
   python ope_mat.py
   python repet_txt.py
   ```
